## 评估结论：迁到微信云开发数据库

写进 `docs/migrate-to-wxcloud.md`。要点：
- 微信云开发免费环境 40,000 点/月（6 个月），之后 ¥19.9/月；文档型库按**读写次数**计费，估月耗 150~500 点（约 1%）。

- 改造面：`utils/cb.js` 540→约 200 行；`cloudfunctions/wxauth` 整目录删除（openid 自动注入）；`genAttraction` 换 wx-server-sdk；`app.js` 加 wx.cloud.init；**页面层零改动**（16 个 cb 方法签名保持）。

## Agent 实验版方案（docs/agent-experiment-plan.md）

用户真实目标是把这个小程序做 Agent 实验田。结论：可行，微信云开发是最合适载体。
- **硬红线**：个人主体无法申请「深度合成-AI 问答」类目（需企业主体 + 算法备案，自主备案 3~13 万）→ **实验版只跑开发版/体验版，不提审**。
- 流式：基础库 2.20.2+ `enableChunked` + `onChunkReceived`，但真机常整段返回 → P0 用「整段 + 前端打字机」。
- 6 个部件：模型接入（云函数出网，免白名单）/ 工具集 function calling / 循环调度（max 3 轮，防云函数 60s 超时）/ chats 会话 / 长期记忆（日记足迹摘要进 system prompt）/ 对话 UI。合计约 4 天。
- 4 个工具直接复用现有数据：searchAttractions、planRoute、getFootprint、saveMemory（写库前必须用户确认）。
- 顺序：先迁微信云开发（地基）→ P0 单轮工具调用（1 天）→ P1 多轮+4工具+会话（2 天）→ P2 流式/内容安全（1 天）。
