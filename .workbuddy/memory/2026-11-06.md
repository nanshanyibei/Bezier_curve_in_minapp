## 四修：DataV 403 防盗链 → 换数据源 geojson.cn
- 关键根因：**geo.datav.aliyun.com 做了 Referer 防盗链**，带 `Referer: https://servicewechat.com/...` 的请求一律 403（实测不带 referer 或带其它 referer 均 200）。小程序无法自定义 Referer → DataV 从原理上不可用于小程序。
- 新数据源：`https://file.geojson.cn/china/1.6.3/{adcode}.json`（geojson.cn，京ICP备16004892号-4，阿里云 OSS+Tengine CDN）。实测带微信 referer 返回 200；省级/直辖市/台湾/港澳全覆盖。
- 字段差异：properties 为 { code, name, fullname, level(1省/2市/3区县), center }；geoSource 新增 normalizeFC() 归一化为内部 { adcode, name, level(city/district/province), center } 后喂给 buildLayer，geoMap 无需改动。
- 变更：config.js GEO_BASE 换源并注释防盗链坑；geoSource 缓存文件名 {adcode}.json、URL 改 .json 后缀、新增 normalizeFC；travel.js 提示文案域名改 file.geojson.cn。
- 验证：四川 21 市 hitTest 21/21；北京 16 区 level=district；URL 拼接正确；node --check 全过。
- 待用户：mp 后台把 **file.geojson.cn** 加入 request + downloadFile 合法域名（已备案，可添加）；开发期工具端关校验即可。
