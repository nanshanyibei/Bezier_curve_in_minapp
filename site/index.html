02 / How it works

曲线是怎么被画出来的

三个概念就够了：端点、控制点、以及把控制点当作「引力」。

01

端点固定

左下角是 0，右上角是 1。曲线从起点出发，最终必须落在终点，不偏不倚。

02

控制点牵引

控制点像磁铁。它离端点越近，曲线起步就越贴近直线；拉远，曲线就被甩出弧度。

03

转换成 CSS

横纵坐标归一化后，就是四个数字。浏览器用它计算每一帧的进度，比手写关键帧省事得多。

cubic-bezier(x1, y1, x2, y2)

其中 x 必须在 0–1 之间，y 可以越界 —— 这就是「回弹」效果的来源。
